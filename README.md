# Практическая работа №11 — RPG на ООП

Консольная игра на C# (.NET 8), группа 3ИСИП-323. Это переработка игры из ПР №6: каждый класс вынесен в свой файл, создание врагов идёт через фабрику.

## Об игре

Каждый ход игрок находит **сундук** или вступает в **бой**:

- в бою можно атаковать или защищаться: блок уменьшает получаемый урон, есть шанс уклониться;
- маги могут **заморозить** игрока, и тот пропускает ход;
- каждый 10-й ход — **босс**;
- в конце выводится, сколько ходов удалось пройти.

Противники: гоблин, скелет, маг, **слизь** (новый враг). Боссы: ВВГ Гоблин-Босс, Скелет-Ковальский, Скелет-Пестов, Архимаг C++.

## Структура (`3ISIP323_Zevakin/Новая папка/`)

- `Enemy` — базовый класс врага; от него наследуются `Goblin`, `Skelet`, `Mag`, `Slime` и боссы;
- `MonsterFabric` — фабрика случайных врагов и боссов;
- `Player` — игрок;
- `Game` — сундуки, бой и главный игровой цикл.

## Что отрабатывалось

Наследование и полиморфизм, паттерн «Фабрика», разделение кода по файлам.

## Запуск

```bash
dotnet run --project 3ISIP323_Zevakin
```
