# Практическая работа №3 — Анализ текста

Консольное приложение на C# (.NET 8), группа 3ИСИП-323.

## Что делает

Для каждого введённого текста считает:

- количество слов и предложений;
- самое короткое и самое длинное слово;
- количество гласных и согласных (русский алфавит);
- частоту каждой буквы (`Dictionary<char, int>`).

Результаты по всем текстам сохраняются в класс `text_history` с автоинкрементным `id`. Меню работает в бесконечном цикле: ввести следующий текст, вывести статистику по всем текстам или выйти.

## Что отрабатывалось

Работа со строками (`Split`, `Contains`), словари, свой класс для хранения результатов, `List<T>`.

## Запуск

```bash
dotnet run --project 3ISIP323_Zevakin
```
