# Практическая работа №7 — Автосервис (Entity Framework)

Консольная игра на C# с базой данных, группа 3ИСИП-323. Работа лежит в проекте **ConsoleApp1**.

## Об игре

Игрок управляет автосервисом. На складе (таблица `pare`) лежат детали: кардан, двигатель, КПП, привод, печка. У каждой случайные себестоимость и количество, стартовый баланс тоже случайный.

Каждый ход приезжает клиент с поломкой, и нужно выбрать деталь для замены:

- деталь выбрана верно — баланс растёт;
- неверно — баланс падает;
- деталь в любом случае списывается со склада;
- между ходами можно докупить детали;
- баланс ушёл в ноль — игра окончена, склад очищается.

## Технологии

- C#, .NET Framework 4.7.2
- Entity Framework 6 (Database First, `Model.edmx`)
- SQL Server, база `avto`

## Запуск

1. Создайте в SQL Server базу `avto` с таблицей `pare` (`ID`, `Name`, `Price`, `count`).
2. При необходимости поправьте строку подключения в `ConsoleApp1/App.config`.
3. Откройте `3ISIP323_Zevakin.sln` в Visual Studio и запустите проект `ConsoleApp1`.
