# 3ISIP323_Zevakin — консольные практики по C#

Практические работы группы 3ИСИП-323. **Каждая работа лежит в отдельной ветке**, в ветке есть свой README с описанием.

| Ветка | Тема | Что отрабатывалось |
|-------|------|--------------------|
| [`Pr1`](https://github.com/Sc0pPP/3ISIP323_Zevakin/tree/Pr1) | Список товаров и услуг | массивы, сортировка, поиск |
| [`pr2`](https://github.com/Sc0pPP/3ISIP323_Zevakin/tree/pr2) | Учёт товаров в магазине | классы, enum, `Stack`, отмена продажи |
| [`Praktika3`](https://github.com/Sc0pPP/3ISIP323_Zevakin/tree/Praktika3) | Анализ текста | строки, `Dictionary` |
| [`pr4`](https://github.com/Sc0pPP/3ISIP323_Zevakin/tree/pr4) | Каталог книг | LINQ: сортировка, группировка, MinBy/MaxBy |
| [`pr5`](https://github.com/Sc0pPP/3ISIP323_Zevakin/tree/pr5) | Университет | ООП, наследование |
| [`pr6`](https://github.com/Sc0pPP/3ISIP323_Zevakin/tree/pr6) | Текстовая RPG | наследование, игровой цикл |
| [`pr7`](https://github.com/Sc0pPP/3ISIP323_Zevakin/tree/pr7) | Автосервис | Entity Framework, SQL Server |
| [`pr8`](https://github.com/Sc0pPP/3ISIP323_Zevakin/tree/pr8) | Интернет-магазин | Entity Framework, авторизация, заказы |
| [`pr11`](https://github.com/Sc0pPP/3ISIP323_Zevakin/tree/pr11) | RPG на ООП | полиморфизм, паттерн «Фабрика» |

WPF-работы (ПР №12–14) лежат в репозитории [3ISIP323_Zevakin_WPF](https://github.com/Sc0pPP/3ISIP323_Zevakin_WPF).

## Как открыть работу

```bash
git clone https://github.com/Sc0pPP/3ISIP323_Zevakin.git
cd 3ISIP323_Zevakin
git checkout pr4
dotnet run --project 3ISIP323_Zevakin
```

Работы pr7 и pr8 сделаны на .NET Framework и запускаются из Visual Studio (подробности — в README этих веток).
