# Практическая работа №5 — Университет (ООП)

Консольное приложение на C# (.NET 8), группа 3ИСИП-323.

## Возможности

- добавление преподавателей (имя, телефон, стаж);
- добавление студентов (имя, группа, курс, телефон);
- создание курса с назначением преподавателя;
- запись студента на курс по `id`.

## Структура

- `person` — базовый класс; от него наследуются `prepod` и `student`;
- `university_course` — учебный курс;
- `University` — класс, где хранятся все списки и вся логика (добавление, запись на курс);
- `Program` — меню.

## Что отрабатывалось

Наследование, инкапсуляция, вынос логики из `Main` в отдельный класс.

## Запуск

```bash
dotnet run --project 3ISIP323_Zevakin
```
