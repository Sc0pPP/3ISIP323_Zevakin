# Практическая работа №4 — Каталог книг (LINQ)

Консольное приложение на C# (.NET 8), группа 3ИСИП-323.

## Возможности

- добавление и удаление книг (название, автор, жанр, год, цена);
- поиск по названию, автору и жанру;
- сортировка по году и по названию (`OrderBy`);
- самая дорогая и самая дешёвая книга (`MaxBy` / `MinBy`);
- группировка по автору с подсчётом книг (`GroupBy`);
- вывод всего каталога.

## Что отрабатывалось

LINQ-запросы, перечисления (`enum genre`), классы, `List<T>`.

## Запуск

```bash
dotnet run --project 3ISIP323_Zevakin
```
