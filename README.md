# Практическая работа №1 — Список товаров и услуг

Консольное приложение на C# (.NET 8), группа 3ИСИП-323.

## Что делает

Пользователь вводит количество позиций, затем каждую позицию в формате `Название; Стоимость`. Дальше можно выбрать:

1. **Статистика** — максимальная, минимальная и средняя стоимость;
2. **Сортировка** — по убыванию стоимости (пузырьковая сортировка двух параллельных массивов);
3. **Поиск** — по подстроке в названии.

## Что отрабатывалось

Массивы, циклы, `switch`, ввод-вывод в консоли, ручная сортировка.

## Запуск

```bash
dotnet run --project 3ISIP323_Zevakin
```
