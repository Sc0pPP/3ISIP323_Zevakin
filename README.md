# Практическая работа №2 — Учёт товаров в магазине

Консольное приложение на C# (.NET 8), группа 3ИСИП-323.

## Возможности

- добавление и удаление товаров;
- поставка: пополнение остатка у существующего товара;
- продажа товара;
- поиск по id, названию и категории;
- вывод всего списка;
- **отмена последней продажи**: история продаж хранится в `Stack<SaleRecord>`;
- **статистика продаж**: сколько продано штук и на какую сумму.

У товаров есть категории (`enum category`). При старте загружается несколько тестовых товаров.

## Что отрабатывалось

Классы, перечисления, `List<T>`, `Stack<T>`, локальные функции, меню в бесконечном цикле.

## Запуск

```bash
dotnet run --project 3ISIP323_Zevakin
```
