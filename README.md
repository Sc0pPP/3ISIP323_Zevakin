# Практическая работа №6 — Текстовая RPG

Консольная игра на C# (.NET 8), группа 3ИСИП-323.

## Об игре

Каждый ход игроку выпадает случайное событие:

- **зелье регенерации**;
- **оружие** (палка, топор, меч уровней 1–3) или **щит** (уровни 1–3). Предмет можно взять или отказаться;
- **бой** с противником. На каждом шаге выбор: защищаться или атаковать.

Противники: гоблин, скелет, маг. Боссы: ВВГ (босс гоблинов), Ковалевский и Песов С-- (боссы скелетов), Архимаг C++.

## Структура

Классы `player`, `enemy`, `weapon`, `armor` и наследники `enemy`: `goblin`, `skelet`, `mag`, а от них боссы.

## Что отрабатывалось

Наследование, случайная генерация событий, игровой цикл.

## Запуск

```bash
dotnet run --project 3ISIP323_Zevakin
```
